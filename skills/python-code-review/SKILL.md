# Python 程式碼審查

當使用者要求審查、檢查或改進 Python 程式碼時,依序檢查下列項目,並針對發現的問題
給出「具體的修正建議 + 修正後的完整片段」。

## 檢查清單

1. **命名**:變數、函式、類別是否清楚一致;避免無意義的 `tmp`、`data2`。
2. **錯誤處理**:是否吞掉例外(`except: pass`);是否該用具體例外型別;資源是否用
   `with` 正確釋放。
3. **邊界條件**:空輸入、`None`、空字串、空集合、超出範圍的索引是否處理。
4. **可變預設參數**:函式參數避免 `def f(x=[])` 這類可變預設值陷阱。
5. **可讀性**:巢狀是否過深(考慮 early return);magic number 是否抽成常數。
6. **一致性**:是否遵循專案既有風格(縮排、引號、型別註記)。

## 輸出格式

- 先用一句話總結整體品質。
- 逐點列出問題,標注嚴重度(🔴 必改 / 🟡 建議 / 🟢 小建議)。
- 對每個「必改」項目附上修正後的完整程式碼片段,不可用「...省略...」。
